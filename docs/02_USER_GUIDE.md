# 使用与排障

核对日期：2026-09-27。系统要求为 Windows 11 x64；运行包须完整保留 DLL、`drivers` 与许可证文件。框架依赖版需要 .NET 10 运行时，自包含版不需要另装运行时。

## 1. 驱动与输入准备

实体输入读取与虚拟输出是两件事。测试已连接的 BLE/Windows 手柄无需安装 USB/IP 虚拟驱动；创建本机虚拟 USB 手柄需要 usbip-win2 驱动及其客户端。

在概览或虚拟手柄页点击「配置 USB/IP 驱动」，使用「安装 / 修复」打开随附安装器，完成系统向导后刷新状态。程序检查随附安装器的哈希及签名，不会在启动时自动安装驱动。卸载入口使用原厂卸载器；未安装或找不到卸载器时不可用。安装、修复和卸载会请求管理员权限，普通运行无需提权。

## 2. NS2 Pro 直连 BLE

1. 确认电脑蓝牙已开启，手柄没有被其他桥接程序占用。在虚拟手柄页选择 NS2 Pro 直连蓝牙输入。
2. 首次接入或普通唤醒失败时长按顶部 SYNC，等待扫描候选出现。自动连接默认开启，也可选中候选手动连接。
3. 等待 GATT 初始化和有效输入；“发现设备”不等于输入已就绪。成功后记录设备地址、地址类型和最近连接信息。
4. 已记录设备可尝试 L + R 或普通按键唤醒。无法回连时重新进入 SYNC，必要时使用下述主机注册。

“停止自动连接”会停止搜索并取消正在进行的连接；“断开连接”还释放当前连接。主动停止后自动连接暂停，需重新开启。连接行为开关只影响本次运行，主机注册开关单独持久化。

候选名称可本地修改，最多 40 字符；保存空白名称恢复原名。这不会改变手柄固件中的名称，也不会把候选标为已成功连接。删除历史会清除该设备的本地名称和注册证据，记录遗忘状态，并断开匹配的当前连接、尝试清理 Windows 配对；系统配对清理失败时会提示手动检查。重新长按 SYNC 可允许重新接入。删除本地记录不等同于擦除手柄内部的主机信息。

### 主机注册与普通唤醒

当前已实现主机注册，不再属于“待授权方案”。「将电脑注册到手柄（默认关闭）」决定是否写入手柄保存的主机信息：

- 需要注册时，在连接前打开开关，然后长按 SYNC；仅在连接开始时有新鲜配对广播才执行。
- 有效输入之后，程序校验地址交换、随机材料、挑战和提交回复。看到“主机注册已确认”才表示收到最终确认；仅输入正常不代表注册完成。
- 完成后可关闭开关，后续普通唤醒不需要每次注册。关闭只阻止后续写入，不撤销已有注册。
- 如果又连接回主机，之后是否需重新注册电脑取决于手柄当前保存的信息。多适配器无法确定对应本机地址时，程序不会猜测。

主机注册写入属于连接功能的显式选项，与 Windows 手柄的系统蓝牙配对流程不同。协议细节见[架构](01_ARCHITECTURE.md)和[注册记录](../ControllerForwardingTool/docs/23_NS2_HOST_REGISTRATION.md)。

## 3. Windows 手柄输入

先接入 USB，或在 Windows 完成对应手柄的蓝牙配对。软件通过 SDL 发现标准手柄和通用 HID；只有标准映射设备可作为转发输入。选择「Windows 手柄 · USB / 系统蓝牙」后，手动选择输入，再启动输出。

本应用输出会从可转发输入列表中过滤，避免自己转发自己。运行中输入选择锁定；选中设备断开后保持中立，不自动切到另一只设备。SDL ID 不持久化，重启后需重新确认 Windows 输入选择。

当前明确阻止 Windows NS2 USB 输入同时输出 NS2 身份，因为其初始化接口需要独占。该组合请改用 NS2 直连 BLE 输入，或选择其他输入手柄/输出身份。

## 4. 输出线路与映射

选择 PS5、NS2 PRO、XBOX、PS5 EDGE、NS1 PRO 中一张卡片，每张卡片拥有独立参数。XBOX 对应 Xbox 360/XInput 身份。点击「应用并保存此线路」后生效；启动输出也会保存当前线路。运行中不能切换输出身份，需先停止。

NS2 按键映射支持未启动输出时编辑。单独保存映射或恢复默认只影响当前线路映射，不提交其他参数草稿。切换卡片保留本次运行的草稿，退出后丢弃未保存部分。支持的目标按键由输出类型决定，未提供的能力不会被自动模拟。

频率默认“跟随输入源帧”；固定频率提供 66/125/250 Hz，“按目标手柄默认 USB 上限”使用项目参考值（NS1 125 Hz，其余 250 Hz）。BLE 实际频率还受连接间隔影响，调高输出值不能提高实体输入采样率。

PS5/Edge 默认开启音频保护，运行中定期检查虚拟 DualSense 是否成为默认播放/录音或通信设备，必要时选择可用的其他端点。音频保护的结果可在日志中查看；这不是游戏声音转发功能。

## 5. 测试、校准与速率

上方“手柄源”只显示实际已连接 BLE 与 SDL 枚举设备。NS2 未连接时无占位卡，断开设备会从列表移除。本应用虚拟输出标为“模拟手柄 · 本应用”；其他 SDL 设备标为“系统手柄”，来源可能是实体，也可能是其他软件的虚拟设备。

**检查 Windows 是否收到输出，必须选择上方已枚举的虚拟设备卡片。** 下方默认折叠的“模拟手柄”是映射参考区，使用当前输入桥已保存的映射状态并按目标布局展示；点击不会切换运行线路、加载另一条线路草稿或启动输出，也不证明 Windows 已收到数据。

可检查按键、摇杆方向/行程、扳机、电量、支持的传感器与震动。电量未知时显示未知；BLE 电量由报文档位解释，不能当作精确电量计。姿态由陀螺仪和重力融合，相对航向不等于磁北绝对航向。

陀螺仪校准需将手柄平放静置；手动校准约 3 秒，移动或缺失数据可能失败。自动静置校准、门限和平滑参数在“陀螺仪校准”页设置，参数修改立即作用于当前运行，保存后下次沿用。计算出的零偏属于当前传感器会话，配置文件保存的是算法参数。

NS2 BLE 摇杆中心/行程校准按设备地址保存；测试页死区是显示预览，实际转发死区在输出线路中设置。震动测试可以调整时长及高低频强度，并手动停止；具体设备可能不支持震动或某种反馈形式。

NS2 USB 初始化接口可能被独占。只把它当测试设备时，离开手柄测试与陀螺仪校准页面可释放该接口；如果同时把 NS2 Windows 设备选作转发源，程序仍需保留输入访问。

## 6. 常见问题

| 现象 | 核对步骤 |
| --- | --- |
| 扫描不到 NS2 | 检查蓝牙与适配器、手柄是否连接到别处；长按 SYNC，查看扫描/GATT 日志。扫描计数为零不能单独证明手柄未广播 |
| 普通唤醒不回连 | 检查自动连接开关、遗忘状态与主机注册证据；重新 SYNC，必要时主动开启注册。单纯存在历史记录不保证主机绑定 |
| BLE 速率低 | 查看实际连接间隔和有效帧率。程序请求高吞吐参数，但协商结果由系统、适配器和设备共同决定 |
| 启动输出失败 | 刷新 USB/IP 状态，检查运行包是否完整、端口是否占用；VIIPER 文件哈希不匹配时恢复随附版本 |
| 显示 NEUTRAL | 输入未就绪或超过约 250 ms 无新状态；检查实体连接与当前输入选择 |
| 参考图有动作但游戏没输入 | 在上方设备卡选择已枚举的模拟设备，确认实际回读，再检查游戏输入设置 |
| 测试页能看到但无法选作源 | 设备可能没有 SDL 标准映射，或被识别为本应用输出；通用 HID 原始测试不代表可转发 |
| 体感、背键或触觉缺失 | 核对源设备是否提供、目标是否支持以及游戏是否发送反馈；Xbox 输出不提供 IMU |
| 默认声音设备变化 | 检查 PS5/Edge 线路音频保护及日志，并在 Windows 核对默认播放/录音设备 |
| 关闭窗口仍有进程 | 默认关闭到托盘；使用托盘“退出”，或保存关闭行为设置 |

设置页提供「打开配置文件」「打开日志目录」，诊断页面可导出日志。反馈问题时提供应用/构建版本、输入型号和连接方式、输出身份、操作步骤及对应日志；数据位置见[配置文档](03_CONFIGURATION_AND_LIFECYCLE.md)。
