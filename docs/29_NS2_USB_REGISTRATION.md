# NS2 Pro USB 注册与连接

NS2 Pro 连接页同时提供 USB 设备选择和蓝牙扫描。实体 USB 输入继续由 SDL 处理，NS2 输入线路优先使用选中的 USB 手柄；拔线时先归零，再接续 BLE 输入。USB 注册不会由蓝牙 SYNC 注册开关触发。

## 使用

1. 连接 USB 数据线，在 NS2 Pro 连接页选择手柄。只有一个首次发现的实体手柄时自动选中；多个设备需手动选择。
2. 插线后自动读取注册状态。电脑须开启一个 BLE 适配器；多个适配器时不猜测注册目标。
3. 显示“未注册到这台电脑”后，点击“注册到这台电脑”。注册可能替换此前主机配对。只有提交回复和存储读回均通过才显示成功。
4. 保持蓝牙和自动连接开启，拔线等待广播并回连。若手柄未自动广播，按 L + R 唤醒。USB 注册交换获得的手柄蓝牙地址与序列号保存在本地，用于限制回连到同一手柄。
5. “删除本机注册”从手柄清除本机配对，再读取确认。删除后可再次点击注册。若存储区同时包含其他主机，按钮禁用，因为公开协议没有可靠的单条删除操作。

“忘记设备”仍只清除本地历史、名称与 Windows 配对。它不等于清除手柄内部注册。历史列表显示“曾确认主机注册”，当前 USB 状态以实际读取为准；读取失败显示未知。

## 实现边界

- USB 管理使用随附 libusb，在 SDL 所在线程临时关闭 Switch 2 驱动、释放接口后独占接口 1。端点从描述符发现，按工厂序列号核对选中的实体 `057E:2069`，拒绝无序列号和本应用的虚拟设备。结束后恢复 SDL。
- 操作短暂中断输入，输出先归零；恢复后按序列号重新选择新 SDL 实例。注册及删除只由按钮触发。
- `02/04` 仅读取工厂序列号、配对项数量及主机地址，不读取配对密钥。配对区 `0x1FA000`，主机地址位于 `0x1FA008 + index * 0x28`，按存储字节序比较。
- 注册复用 `15/01 → 04 → 02 → 03` 协商，USB 传输字段为 `00`，ACK 为 `F8`；BLE 原有 `01` / `78` 校验保留。挑战失败不提交，提交不重发，最后读回确认本机地址。
- 删除仅在所有有效条目均为当前主机时发送 `03/08`，再确认项数为零。遇到未知布局或其他主机时不清空、不直接改写 flash。
- 命令回复、读取地址和长度均校验；超时/取消显示结果未知，不能据此声称设备没有保存。密钥不写入日志或设置。
- 当前仅支持一个选中的 USB 输入。输出同样的虚拟 NS2 身份时保留原有 USB 独占限制；应先切换蓝牙输入，或使用其他虚拟身份。
- 曾通过其他方式注册的 USB 手柄可以根据存储中的主机地址显示已注册，但若没有序列号与蓝牙地址映射，则仍按原有 BLE 自动连接策略发现设备。

## 验证

协议检查覆盖只读查询、四阶段 USB 注册、重复注册不写入、错误挑战、提交与删除的存储读回、保留其他主机、取消、错误地址/传输、公开 AES 向量，以及 USB 优先、断线归零和 BLE 接续。设置检查覆盖地址映射往返和旧配置空字段。
