# 手柄转发工具 / Controller Forwarding Tool

让手柄或键盘 / 鼠标以另一种手柄身份在 Windows 游戏中使用。支持 **NS2 Pro USB / 蓝牙直连**、**Windows 已连接的手柄**和**键鼠输入**，可输出 NS2 Pro、NS1 Pro、Xbox 360、PS5 或 PS5 Edge 虚拟手柄，并提供按键映射、体感、震动测试与校准。

**当前版本：1.0.1** · **系统：Windows 11 x64**

## 安装与首次启动

### 准备运行程序

- **安装包**：按向导安装。默认仅为当前用户安装；选择为所有用户安装时会请求管理员权限。首次安装默认勾选登录 Windows 后自启，可在安装时取消。
- **便携运行包**：完整解压后运行 `ControllerForwardingTool.exe`。请保留同目录的 DLL、`drivers` 和许可证文件，不要只复制 EXE。
- **运行时**：自包含版已附带 .NET 运行时；框架依赖版需要 .NET 10 运行时。

普通运行无需管理员权限。安装或修复虚拟手柄驱动时，程序会单独请求权限。

### 第一次完成转发

1. 打开「概览」或「虚拟手柄」，点击「配置 USB/IP 驱动」，执行「安装 / 修复」。完成安装向导后刷新驱动状态。**仅测试实体手柄时无需安装这个虚拟输出驱动。**
2. 按下文连接实体手柄，或直接使用「键盘 / 鼠标」。进入「虚拟手柄」，选择输出身份，并确认「输入设备」中选中了要操作的设备。
3. 暂时保留线路参数的默认值，点击「启动虚拟 USB · 自动连接」。启动时会应用并保存当前线路。
4. 等待 Windows 识别成功，在「手柄测试」上方选择当前的「模拟手柄 · 本应用」，按键或推动摇杆，确认接收状态。键鼠输入需点击「开始键鼠测试」或按 F8。
5. 在游戏或模拟器中选择刚创建的虚拟手柄。需要改键时，进入此时出现的「按键映射」页面，修改后点击「应用并保存」。
6. 结束使用时点击「停止当前输出」；要关闭软件，从系统托盘菜单选择「退出」。默认点击窗口关闭按钮会继续后台运行。

**输入设备**是你实际操作的手柄或键鼠，**输出身份**是 Windows / 游戏看到的虚拟手柄型号。两者可以不同；同一软件实例同时运行一条输出线路。切换输入或输出身份前，先停止当前输出。

## 选择输出身份

根据游戏或模拟器支持的手柄类型选择输出卡片：

| 输出卡片 | 游戏中使用的身份 | 能力与注意事项 |
| --- | --- | --- |
| XBOX | Xbox 360 / XInput | 按键、摇杆、模拟扳机和普通双马达震动；不支持体感 |
| NS1 PRO | Switch Pro Controller | 按键、摇杆、体感和震动；扳机按数字按键处理 |
| NS2 PRO | Switch 2 Pro Controller | 按键、摇杆、体感、C / GL / GR 和震动；实体 NS2 USB 输入不能同时输出此身份 |
| PS5 | DualSense | 按键、摇杆、模拟扳机、体感及普通 / HD 震动处理；效果取决于输入设备和游戏 |
| PS5 EDGE | DualSense Edge | 按键、摇杆、模拟扳机、体感、背键和普通震动 |

体感、背键和震动是否可用，还取决于输入配置及游戏支持。Windows 手柄的震动回传使用普通马达能力；不能据此获得完整 HD 波形或自适应扳机阻力。鼠标可以模拟体感，Xbox 输出仍不会发送体感。

虚拟手柄只提供给**这台 Windows 电脑**使用，不能把电脑的 USB 接口当作连接 Switch 主机的实体手柄。

**1.0.1 首次运行默认选中 NS1 PRO 线路。** 此线路预设会将实体 A / B 互换、Plus 设为不输出，并开启键鼠补充；GL / GR 对应左右摇杆按下。其他线路有各自的默认映射，升级保留已有配置。开始游戏前可在「全部映射」确认实际键位。

## 连接输入设备

### NS2 Pro：USB 有线连接

1. 使用支持数据传输的 USB 线连接手柄，打开「NS2 Pro 连接」。
2. 在 USB 设备列表中选择手柄。首次只发现一只实体手柄时会自动选中；有多只时手动选择。
3. 等待显示「USB 已连接」，点击「测试 USB 输入」检查按键和摇杆。
4. 回到「虚拟手柄」，选择该 NS2 输入设备和所需输出身份，再启动输出。

NS2 输入线路优先使用选中的 USB 手柄；拔线后先归零，再等待蓝牙接续。要使用蓝牙，请保持电脑蓝牙及自动连接开启。**实体 NS2 USB → 虚拟 NS2 PRO 的组合受接口独占限制**，请改用蓝牙输入或其他输出身份。

如果 Steam 能识别手柄而这里提示「检测到设备但接口无法打开」，从 Steam 菜单彻底退出 Steam，并退出其他占用手柄的工具。仅关闭窗口可能仍在后台运行。接口释放后软件约每 3 秒自动重试，也可点击「重新检测 USB」；仍失败时检查数据线和驱动。

### NS2 Pro：蓝牙直连

1. 开启电脑蓝牙，在「NS2 Pro 连接」中开启「自动连接」，或点击「扫描手柄」。使用蓝牙前拔下 USB 数据线。
2. 首次连接时长按手柄顶部 **SYNC**，等待设备出现。软件默认自动连接，也可选择候选手动连接。
3. 等待显示连接成功且出现有效输入，再到「虚拟手柄」选择这只 NS2 作为输入。
4. 后续可尝试 **L + R** 或普通按键唤醒；无法回连时重新长按 SYNC。

点击「停止搜索 / 连接」或主动断开后，自动连接会暂停；继续使用时需重新开启。设备历史可以重命名，名称只在本软件中使用。「忘记设备」会清除本地记录、名称并尝试清理 Windows 配对，还会断开匹配的当前连接。

### 可选：将电脑注册到 NS2 手柄

注册用于让手柄记住这台电脑，不是每次转发都必须操作。注册可能替换原先保存的主机信息，之后切回主机可能需要重新配对。

| 方式 | 操作 |
| --- | --- |
| 通过 USB 注册 | 在「NS2 Pro 连接」选择 USB 手柄，等待读取状态，再点击「注册到这台电脑」。电脑需开启一个可明确识别的蓝牙适配器；有多个适配器且无法确定目标时不会猜测 |
| 通过蓝牙 SYNC 注册 | 在连接前开启「蓝牙 SYNC 连接时注册电脑（默认关闭）」，然后重新长按 SYNC 连接，等待注册确认 |
| 删除手柄中的本机注册 | USB 连接后点击「删除本机注册」。若同时存有其他主机，当前不支持单独删除，会禁用该操作 |

USB 插线默认只读取状态，写入和删除由按钮触发；不受蓝牙 SYNC 注册开关控制。关闭蓝牙注册开关不会撤销已有注册；「忘记设备」也不会清除手柄内部注册。历史中的「曾确认主机注册」不代表当前存储状态，可用 USB「刷新注册状态」核对。

USB 注册、拔线回连与删除再注册流程尚未完成完整实机验收，具体限制见 [NS2 USB 注册与连接](docs/29_NS2_USB_REGISTRATION.md)。

### Xbox、Switch Pro、PlayStation 等 Windows 手柄

1. 使用 USB 连接，或先在 Windows 设置中完成蓝牙配对。
2. 打开「虚拟手柄」，点击「刷新输入设备」，选择对应的实体手柄卡片。
3. 选择输出身份并启动。运行中输入选择会锁定，需要更换手柄时先停止输出。

只有具备标准按键映射的设备才能作为转发输入。部分通用设备可以在测试页查看原始按钮和轴，但无法用于转发。本应用创建的虚拟输出不会列为自己的可用输入，避免循环转发。

Windows 手柄的具体设备选择不会跨启动保存，重启后请重新确认。加载线路或启动输出时若实体输入不可用，软件会选择键鼠；**运行中实体手柄断开则归零，不会自动切换到另一只手柄或键鼠。**

## 键鼠与混合控制

### 只用键盘和鼠标

在「虚拟手柄」选择「键盘 / 鼠标」，再选择输出身份并启动。无需实体手柄，但仍需虚拟输出驱动。

| 操作 | 效果 |
| --- | --- |
| 切换到游戏后按 F8 | 开始键鼠控制；再次按 F8 暂停 |
| 按 Esc | 暂停键鼠控制并释放鼠标 |
| 切换前台窗口，或按 Alt / Windows 键 | 自动释放键鼠控制，输入状态归零；回到游戏后需重新按 F8 |
| 停止输出或退出软件 | 结束捕获并清空输入状态 |

鼠标功能在「按键映射」的源输入图下设置，可选「右摇杆」或「陀螺仪」；Xbox 输出使用右摇杆。停止移动后摇杆回中或角速度归零。切换鼠标模式会暂停控制，需要重新按 F8。

以下为**没有自定义覆盖时的通用键位**；面键名称会随输出型号变化：

| 键盘 / 鼠标 | 对应操作 |
| --- | --- |
| W / A / S / D | 左摇杆 |
| 方向键 | 十字键 |
| J 或空格 / K / U / I | 下 / 右 / 左 / 上四个面键 |
| Q / E | 左 / 右肩键 |
| 鼠标右键 / 左键 | 左 / 右扳机 |
| Shift / Ctrl | 左 / 右摇杆按下（L3 / R3） |
| Enter / Tab | 开始（+）/ 返回（−） |
| F1 / C | Home / 截图，需输出身份支持 |

**NS1 PRO 新建线路使用专门预设，不完全采用上表：**

| NS1 预设键位 | 输出操作 |
| --- | --- |
| W / X / A / D | 左摇杆上 / 下 / 左 / 右；向下是 X |
| K / L / J / I | B / A / Y / X |
| Q / E；1 / 4 | L / R；ZL / ZR |
| Z 或鼠标右键 / C | 左 / 右摇杆按下 |
| 方向键 | 十字键 |
| 空格 / N / M / B | Plus / Minus / Home / 截图 |
| 鼠标左键 | A |
| 鼠标移动 | 默认模拟陀螺仪 |

请以当前线路「全部映射」中的实际配置为准。自定义绑定会优先于通用键位，例如把 W 改绑为按钮后，它不会再同时推动左摇杆。

软件不会屏蔽游戏自身的键鼠输入；如果游戏同时响应键鼠和虚拟手柄，请检查游戏的输入方式设置。纯键鼠输入不会将游戏震动转发给其他已连接的手柄。

### 实体手柄搭配键鼠补充

1. 选择实体输入并启动输出，进入「按键映射」。
2. 开启「键盘 / 鼠标补充」，双击目标按钮，为它添加键盘键或鼠标按键。
3. 需要鼠标体感时选择来源：「自动」优先实体手柄，无体感时用鼠标；也可固定为「实体手柄」或「鼠标」。Xbox 输出不显示体感来源选择。
4. 点击「应用并保存」，切换到游戏后按 F8 开始补充输入。

补充模式只发送明确配置的键鼠按钮，不会自动启用通用 WASD / J 等键位；摇杆始终由实体手柄控制。多个来源可对应同一按钮，全部松开后才释放；键鼠扳机按下为满行程，松开后恢复实体扳机行程。

Esc / F8 暂停补充后，实体手柄继续工作。关闭补充开关会立即清空补充状态并保留绑定；实体输入断开或超时，整个混合输出归零。新建 NS1 线路默认开启补充，其他线路及旧配置缺省时关闭；**开启开关不等于已经按 F8 开始控制。**

## 修改按键映射

**先启动虚拟输出，等待 Windows 识别当前模拟手柄，映射入口才会出现。** 输入可以是 NS2 USB / 蓝牙、Windows 标准手柄或键鼠。

1. 在「虚拟手柄」点击「打开按键映射」，或从左侧导航进入「按键映射」。
2. 单击输出按钮，查看对应的全部输入来源；双击该按钮打开编辑弹窗，可添加多个手柄按钮、键盘键或鼠标按键，也可逐项移除。
3. 绑定鼠标左键时使用弹窗内的专用选项，避免将点击确认按钮误录为绑定。按 Esc 或取消会丢弃本次弹窗未确认的修改。
4. 点击弹窗「确认」后，在页面预览草稿；确认正确，再点击右上角「应用并保存」，使映射用于实际输出并在下次启动保留。

| 功能 | 使用方式 |
| --- | --- |
| 手柄状态 / 全部映射 | 前者查看当前输入与草稿效果，后者按输出目标列出全部来源；双击映射卡片可编辑整组来源 |
| 快速配置 | 逐项录入左右摇杆和按钮；每次先松键或让摇杆回中，再输入下一项。「跳过此项」保留原配置 |
| 双击摇杆 | 在「摇杆按下」页设置 L3 / R3；在「摇杆」页配置实体左右轴，或纯键鼠的四个方向 |
| 不输出 | 禁用对应源按钮的输出 |
| 恢复默认并保存 | 恢复当前输出线路的默认按键、摇杆、键鼠及相关设置；NS1 会恢复其专门预设 |

实体摇杆录入需推动一个源摇杆，普通按钮和 L3 / R3 不能代替轴。Esc、F8、Alt 和 Windows 键保留给运行控制，不能绑定为游戏按钮。

映射页显示的是**当前草稿预览**，未保存或键鼠控制暂停时也可能有动作；是否真正发到 Windows，请到「手柄测试」选择实际枚举的模拟设备检查。停止输出或设备消失会隐藏映射入口、取消未确认录入，已有草稿在本次运行中保留，退出后未保存部分丢弃。

## 手柄测试与校准

在「手柄测试」上方选择要检查的设备：

| 设备 / 区域 | 用途 |
| --- | --- |
| 已连接的 NS2 蓝牙手柄或系统手柄 | 查看该设备的实际输入；「系统手柄」也可能是其他软件创建的虚拟设备 |
| 模拟手柄 · 本应用 | 查看 Windows 实际收到的本软件虚拟输出，检查改键与转发是否生效 |
| 下方折叠的模拟手柄参考区 | 按已保存的映射查看参考效果，不证明 Windows 或游戏收到了输入，也不会启动输出 |

按键、摇杆、模拟扳机、电量和体感会按设备能力显示。点击实体输入卡或测试设备卡会发送一次 **25% 强度、250 ms** 的识别振动；键鼠卡和映射参考卡不振动。

**测试键鼠输出**：选中当前「模拟手柄 · 本应用」，点击「开始键鼠测试」。先松开用于点击或确认的按键，再操作键鼠；测试期间页面控件不会响应这些游戏按键。按 Esc / F8 结束测试，恢复页面操作。

**校准陀螺仪**：选择提供体感的设备，进入「陀螺仪校准」页，将手柄平放静置，手动采样约 3 秒。移动或传感器数据不足可能导致失败。自动静置校准、门限和平滑也在这里设置；修改算法参数后需要保存，采样得到的零偏用于当前会话。

**校准 NS2 蓝牙摇杆**：保持蓝牙连接，在「虚拟手柄」的双摇杆校准区域，先松手执行「中心 · 2 秒」，再执行「完整行程 · 8 秒」，将两个摇杆沿边缘转满。结果按这只手柄保存；需要撤销时点击「重置校准」。Windows / USB 输入使用系统读取的轴值。

震动测试可设置强度和时长，也可手动停止。电量未知表示设备未提供有效信息；体感姿态和输入频率属于辅助读数，不应当作精确电量计、绝对航向或游戏帧率。

## 常用参数与保存方式

每种输出身份有独立线路，修改 NS1 的映射和震动不会覆盖 Xbox 等其他线路。

| 参数 | 调整后的效果 |
| --- | --- |
| 震动倍率 | 默认 0.7x；0 关闭回传震动，1 为原始强度，最高 3x。最终效果取决于输入设备 |
| 推送频率 | 默认跟随输入源帧，也可选 66 / 125 / 250 Hz，或目标默认参考值（NS1 125 Hz，其余 250 Hz）。提高数值不会提高实体手柄的采样率 |
| 实际输出死区 | 默认 0%；摇杆中心漂移时可增加，范围 0–30%。测试页的死区只改变预览，实际转发要在输出线路中设置 |
| PS5 音频保护 | PS5 / Edge 默认开启，防止虚拟手柄接管 Windows 默认播放或录音设备；必要时可点击「立即修复默认音频」 |
| PS5 体感方向与倍率 | 调整 PS5 / Edge 输出的俯仰、偏航、横滚及反向；不改变原始输入读数 |
| 本地服务端口 | 通常保留 0 自动选择；修改端口后需停止并重新启动输出 |

| 保存入口 | 保存什么 |
| --- | --- |
| 虚拟手柄页「应用并保存此线路」 | 当前线路的输入、映射、震动、频率、摇杆及体感等设置；启动输出也会执行保存 |
| 映射页「应用并保存」 | 当前线路的按键、摇杆、键鼠、鼠标模式、补充开关及体感来源，不提交其他页面未保存的参数草稿 |
| 设置页「保存软件设置」 | 自启、启动恢复输出及托盘 / 窗口行为 |

切换输出卡片会保留本次运行的草稿，退出后只保留已保存内容。补充开关在运行中立即启停补充输入，保存后才跨启动保留。

## 后台运行、配置备份与升级

默认「关闭窗口时保留后台运行」开启，关闭窗口后转发继续；可从系统托盘重新打开窗口或选择「退出」。要让关闭按钮直接退出，在「设置」取消该选项并点击「保存软件设置」。

设置页还可启用登录 Windows 后自启、启动后恢复虚拟输出、启动 / 最小化到托盘。恢复输出需要驱动可用；实体输入不可用时会选择键鼠，键鼠仍需 F8 开始控制。安装版首次自启选项与便携版默认设置不同；安装到所有用户并启用的自启入口，需要重新运行安装器取消。

在「设置」点击「打开目录」，进入 `%LOCALAPPDATA%\ControllerForwardingTool`：

| 文件 / 文件夹 | 内容 |
| --- | --- |
| `bridge-settings.json` | 线路与映射、软件设置、设备历史和校准配置 |
| `window-placement.json` | 窗口位置与大小 |
| `logs/` | 自动运行日志及手动导出的诊断信息 |

备份或手动编辑配置前，先停止输出并从托盘退出程序，再复制上述配置文件。升级前同样完整退出软件，安装版升级后保留用户数据；便携版请完整解压新运行包，避免只更换 EXE 导致依赖不一致。卸载应用保留用户数据，USB/IP 系统驱动仍由驱动面板单独管理。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 启动按钮不可用或提示缺少驱动 | 打开「配置 USB/IP 驱动」，完成安装 / 修复并刷新状态；检查运行包是否完整 |
| 启动虚拟输出失败 | 在日志查看原因，检查驱动、运行文件和端口；后端文件校验失败时恢复完整运行包 |
| NS2 USB 列表为空，但 Steam 能识别 | 彻底退出 Steam 等占用程序，保持插线等待重试或点击「重新检测 USB」；再检查数据线与驱动 |
| 蓝牙扫描不到或无法回连 | 确认蓝牙开启，检查手柄是否连接到别处；长按 SYNC。主动停止后重新开启自动连接，必要时核对主机注册状态 |
| 重启后选中了键鼠 | 实体输入当时不可用，或 Windows 设备选择未保留；停止输出、连接手柄并重新选择输入 |
| 看不到按键映射入口 | 等待虚拟输出启动成功并被 Windows 识别；停止、启动失败或设备消失时入口会隐藏 |
| 映射图有动作，游戏没有输入 | 先「应用并保存」，再在测试页选择「模拟手柄 · 本应用」检查实际回读，最后检查游戏的手柄选择 |
| 键鼠不响应，或切回游戏后停止了 | 在游戏窗口按 F8；Alt / Windows 键和切换窗口会暂停。实体混合输入还需开启补充并保持手柄在线 |
| NS1 的按键与预期不同 | 新建线路有 A / B 互换、Plus 禁用和专门键鼠预设；在「全部映射」查看并修改，恢复默认也会恢复这些预设 |
| 状态显示 NEUTRAL 或按键突然归零 | 输入未就绪、键鼠未开始控制或约 250 ms 没有有效输入；检查当前输入选择和连接 |
| 测试页能看到设备，却不能用于转发 | 设备可能没有标准映射，或属于本应用的虚拟输出；能读取原始按钮不代表可以转发 |
| 没有体感、背键或震动 | 核对源设备、输出身份及游戏支持；Xbox 输出没有体感，震动倍率为 0 时不回传 |
| 声音输出设备被改变 | 检查 PS5 音频保护，点击「立即修复默认音频」，并在 Windows 声音设置中确认默认设备 |
| 关闭窗口后程序仍在运行 | 默认关闭到托盘；使用托盘「退出」，或修改并保存关闭窗口的行为 |

反馈问题时，提供「关于」页的软件版本与构建时间、输入手柄型号及连接方式、输出身份、复现步骤，以及 `logs/` 中对应的日志。不要用映射预览图代替实际接收结果。
