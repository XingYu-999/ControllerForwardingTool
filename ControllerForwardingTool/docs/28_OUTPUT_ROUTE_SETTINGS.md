# 独立输出线路配置

> 历史记录（1.0.1 文档同步，2026-09-27）：正文保留当时的设计、功能状态与验证结果，不作为当前操作说明。当前键鼠 / 混合输入、全输入映射、NS2 USB 连接及默认配置见[当前文档目录](../../docs/README.md)和[1.0.1 更新日志](../../CHANGELOG.md)。

五条线路按输出身份区分：PS5、PS5 Edge、Xbox、NS1 Pro、NS2 Pro。USB 与蓝牙输入不再进一步拆分配置。

每条线路保存输入类型、NS2 按键映射、震动倍率、推送频率、音频保护、摇杆死区、是否应用设备校准、PS5 体感倍率与方向、API/USB 端口。实际校准数据按实体设备共用，应用自启、托盘和蓝牙设备记录仍为全局配置。

在虚拟手柄页选择输出卡片，然后编辑并点击「应用并保存此线路」。启动输出也会保存当前线路的参数和映射。运行期间不能切换线路。停止输出后可离线编辑映射；映射页保存或恢复默认仅修改当前线路的映射，不提交振动等参数草稿。

切换卡片会保存本次内存草稿，包括尚未保存的映射和参数；草稿不会因保存另一条线路而写入文件。重新启动时载入最后保存的线路及其已保存配置。保存失败保留草稿，运行中的映射和震动参数保持原值。

配置文件新增 `OutputRoutes`，按 `VirtualControllerMode` 保存。顶层输出字段作为当前运行快照及旧版迁移来源保留。旧配置没有线路字典时，以旧值分别初始化五条线路；映射字典相互独立。软件设置和设备记录的保存保留所有线路配置。

验证：构建解决方案、运行 `ControllerForwardingTool.Checks`，并通过 `--render-routes <目录>` 检查线路切换、草稿隔离、保存失败、五种离线映射布局及窄宽页面。测试不修改真实用户配置，不连接蓝牙设备。硬件震感与游戏接收效果仍需实际手柄验证。
