# 键盘 / 鼠标输入

适用版本：**1.0.1**；同步日期：2026-09-27。[更新日志](../../CHANGELOG.md) · [当前文档目录](../../docs/README.md)。

所有输出身份（PS5、NS2 Pro、Xbox、PS5 Edge、NS1 Pro）均可在没有实体手柄时启动。仍需先准备 USB/IP 驱动。此前保存为 Windows 手柄输入且没有选中设备的线路会禁用启动按钮；现在不再以实体输入是否存在限制启动，无可用输入时默认选择键鼠。

在输入卡片中选择“键盘 / 鼠标”，选择输出身份并启动。切换到游戏后按 **F8** 开始控制，再按 F8 暂停，**Esc** 释放鼠标。切换前台窗口、按 Alt / Windows 键、停止输出或退出应用均会释放并归零。运行中不会因实体手柄断开而自动接管键鼠。

在“手柄测试”页选择当前输出的“模拟手柄 · 本应用”，点击 **开始键鼠测试** 或按 F8 即可验证实际接收。页面显示未启动、选错设备、已暂停或正在转发的状态。启动按钮的点击 / 回车 / 空格需释放后再次按下才会发送；测试期间应用控件不会响应游戏按键或鼠标点击，Esc / F8 退出后恢复操作。离开测试页、切换测试设备、切换窗口和停止输出会归零。

按键映射页在虚拟输出启动并被 Windows 识别后开放。本地预览使用当前草稿，确认配置后无需先保存即可测试，键鼠转发已暂停时仍会亮起；这不表示 Windows 收到了输入。手柄测试页始终读取系统手柄数据。实体输入的“键盘 / 鼠标补充”在新建 NS1 线路中开启，其他线路及旧配置缺省时关闭；关闭时不预览或转发补充输入，纯键鼠主输入不受此开关限制。

纯键鼠的通用鼠标模式为右摇杆，NS1 新建线路预设为陀螺仪；可在映射页的源输入图下选择。停止移动后摇杆回中或角速度归零。切换鼠标模式会暂停控制，需要重新按 F8。模式随输出线路保存，点击映射页右上角“应用并保存”或启动输出时保存。虚拟手柄页不再重复显示键鼠模式和补充设置。

下表是无自定义覆盖时的通用绑定。**首次运行的 NS1 线路另有预设**：左摇杆 W/X/A/D，K/L/J/I → B/A/Y/X，鼠标左键 → A，鼠标右键 → L3，空格 → Plus 等，详见[配置与默认值](../../docs/03_CONFIGURATION_AND_LIFECYCLE.md)。绑定按当前线路显示，不应将下表当作所有线路的实际键位。

| 键鼠 | 手柄输入 |
| --- | --- |
| WASD | 左摇杆，斜向归一化 |
| 方向键 | 十字键 |
| J / 空格、K、U、I | 下、右、左、上四个面键，按输出布局显示 |
| Q / E | 左 / 右肩键 |
| 鼠标右键 / 左键 | 左 / 右扳机 |
| Shift / Ctrl | 左 / 右摇杆按下 |
| Enter / Tab | 开始（+）/ 返回（−） |
| F1 / C | Home / 截图（支持的输出） |

键鼠输入不发送选中振动，也不把游戏振动转发到其他已连接手柄。虚拟手柄页的实体输入卡片和手柄测试页的已连接设备卡片，每次点击均发送一次 25% 强度、250 ms 的识别振动。Windows 设备经 SDL 发送，NS2 直连蓝牙使用限时振动；测试页的“映射参考”卡片不发送振动。

Xbox 输出没有原生陀螺仪，使用右摇杆模式。其他身份的体感使用需要游戏支持。当前实现读取键鼠状态并在控制时将光标复位，不屏蔽游戏自身的键鼠输入；同时接收键鼠和手柄的游戏可在游戏设置中选择手柄输入。

自动检查覆盖映射、回中、捕获 / 释放、失焦、输出停止、输入源隔离和线路配置保存；实际游戏兼容性需在 Windows 游戏环境验证。
