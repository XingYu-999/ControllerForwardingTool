# 手柄测试、陀螺仪校准与 NS1 稳定性

## 型号与布局

测试页根据 VID/PID 和 SDL 的手柄类型选择图形。Switch Pro 与 Switch 2 Pro 使用 Nintendo 的 X/A/B/Y 顺序和非对称摇杆；只有 Switch 2 Pro 显示 C、GL/GR（标注为背键）。Xbox 使用 Y/B/A/X 与 LB/LT/RB/RT。DualShock 3、DualShock 4、DualSense、DualSense Edge 使用对称摇杆和 △/○/×/□，分别显示 Select/Start、Share/Options、Create/Options、触摸板和相应背键。

按钮读数只列出 SDL 报告存在的按钮，轴读数标注左右摇杆、扳机和 Hat。第三方设备优先采用 SDL 类型；无法确定型号时标记通用布局，未知 HID 仍按原始编号显示，不能保证其轴顺序或外形与通用图一致。

左侧导航参考本地 `D:\github\VirtualDriverControl` 的图标、居中对齐、蓝色选中态和可折叠设计。设置与关于固定在底部；折叠后保留图标、提示和无障碍名称。

## 陀螺仪

手柄图右侧显示原始角速度、减去零偏后的角速度、当前零偏与校准状态，单位 °/s。加速度以 g 显示。姿态图根据重力估算俯仰、侧倾，不表示陀螺仪积分航向。

1. 选择有陀螺仪及加速度计的输入源，确认有新传感器数据。
2. 将手柄放在稳定平面，点击「校准 · 3 秒」，保持静止。
3. 采集满 3 秒且至少 150 个有效新样本，通过静止检测后才提交零偏。
4. 可取消或重置；移动、数据延迟、断流和样本不足会显示失败原因，并保留上一次有效零偏。

校准方法参考 clone 工程 `source/final-three-in-one/windows/v60_viiper_app/ProfessionalImuPipeline.cs` 的 `ImuCalibrationState`：加速度模长 0.85–1.15 g，模长标准差 <0.02 g，每轴角速度标准差 <3/16.384 °/s，相邻角速度向量差 <40/16.384 °/s，样本延迟不超过 150 ms。另限制平均角速度向量长度不超过 5 °/s，避免将持续旋转当作零偏；连续 500 ms 无输入或整体 5 秒超时则失败。

Windows 输入按 SDL 新陀螺仪事件采样，m/s² 换算 g，rad/s 换算 °/s，UI 的 30 Hz 刷新不计作额外样本。BLE 仅在运动时间戳更新时采样，使用参考工程比例 4096 raw/g、16.384 raw/(°/s)。这些比例仍需不同 NS2 固件实测，不能代替工厂标定。

Windows 校准按本次设备实例保存，仅影响测试读数；拔出设备后清除。BLE 校准在本次程序会话内对同一地址保留，切换实体设备清除；同时用于 NS2 虚拟输出的角速度零偏修正。不写入手柄、不保存到固件。NS1 映射预览没有 IMU，NS1 虚拟输出的 IMU 转换仍未实现，不能借此页面推断已支持。

## 震动配置

Windows 手柄输入源提供 50–10000 ms 时长、低频/高频各 0–100% 力度，默认 1000 ms、各 25%。点击开始才发送，支持手动停止，切换输入源/设备和关闭设备时请求停止。底层同时限制参数范围和指令有效期；设备忙超过期限时不会补发过期震动。

设备不支持震动或发送失败时显示错误。NS2 BLE 直连的震动回传尚未实现；本应用创建的虚拟手柄收到请求，只代表主机反馈链路工作，不代表实体 NS2 马达动作。

## NS1 卡死修复

原路径在 Avalonia UI 线程上启动 USB/IP 异步服务，其后续应答继承 UI 同步上下文；同一 UI 线程又同步执行 SDL HID 初始化。NS1 初始化等待 USB 应答，而应答等待 UI 线程，导致相互等待。本机 Windows 日志曾出现两次 AppHangB1，未取得独立原生崩溃堆栈。

- USB/IP 接收循环从线程池启动，不继承 UI 同步上下文。
- SDL 初始化、热插拔、打开设备、事件泵、读数、震动和释放统一在专用线程执行；UI 只读取发布的快照。
- 没有新快照时清除测试状态，设备指令有超时，退出最多等待输入线程 3 秒。

## 验证

```powershell
dotnet build ControllerForwardingTool.slnx
dotnet run --project NS2ProWin11.Checks
# 已安装 USBip 时运行；仅创建和清理测试自己的临时设备
dotnet run --project NS2ProWin11.Checks -- --attach-monitor
dotnet run --project NS2ProWin11.Checks -- --attach
```

默认检查覆盖型号与按钮标签、震动边界、静置校准成功、移动/重复/延迟/断流失败、保留旧零偏、重置，以及无 UI 消息泵条件下 USB/IP 列举和 HID 控制传输。`--attach-monitor` 使用与界面相同的 SDL 线程，连续三轮 NS1 挂载、读取合成输入、断流归零与停止。

本机实体 NS2 USB（057E:2069）也完成一次实际校准：3 秒采集 753 个有效样本，零偏约 X 0.73、Y 0.25、Z −0.18 °/s；一次校准后的静置读数约 X 0.00、Y 0.05、Z −0.06 °/s。该结果验证 Windows/SDL 传感器事件、采样和 UI 校准完整路径，不是 BLE 路径或长期漂移指标。马达实际强度、长期漂移及其他型号仍需各自实测。
