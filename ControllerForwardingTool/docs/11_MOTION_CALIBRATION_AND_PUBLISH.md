## 手柄布局

参考用户提供的 Steam 控制器状态截图重新绘制浅色矢量外壳，降低壳体底部内凹位置，并为完整摇杆行程圈预留空间。十字键、右摇杆及其移动范围现在位于外壳内。

- Switch Pro：非对称摇杆、Nintendo ABXY、独立截图/Home、减号/加号与四向十字键。
- NS2 Pro：保留 C、GL/GR；背键放在握把下部并标注。
- Xbox：非对称摇杆及 Xbox 面键顺序，LT/RT 保留独立线性行程填充和百分比。
- PlayStation / Edge：对称摇杆、触摸板、方向键与形状面键，Edge 背键独立显示。
- 十字键常驻四向箭头，斜向输入同时点亮两个方向；摇杆移动与 L3/R3 按下分别表现。

绘图位于 `Views/ControllerTesterControl.cs`。没有复制 Steam 的图片或程序代码。

## 三轴姿态

旧预览把加速度作为两个受限欧拉角，并将 SDL 的重力方向误当作 Z 轴，平放时也可能显示错误倾斜。新预览在输入线程融合陀螺仪与重力，使用四元数表示连续姿态，支持俯仰、偏航、横滚及翻转。

计算方式参考本机 `D:\github\eden` 中 `src/hid_core/frontend/motion_input.cpp` 的角速度积分、重力反馈和时间间隔保护思路；使用 System.Numerics 独立实现，没有移植 eden 源码。渲染为具有厚度、面遮挡和透视的模型，顶部箭头指向手柄前方，地面网格保持固定。

[SDL 传感器坐标说明](https://wiki.libsdl.org/SDL3/SDL_SensorType)：X 向右、Y 向上、Z 朝向使用者，平放重力约为 +Y；角速度使用右手坐标。内部统一为 g 与 °/s。NS2 BLE 原生坐标按 `(x, z, -y)` 转换，校正后的虚拟输出再转换回原生坐标。

仅用新的有效传感器样本推进姿态，重复时间戳不积分；超过 100 ms 的积分间隔不直接累积，超过 250 ms 的输入空隙重新对齐重力。无数据时显示灰色模型，不将 UI 刷新当成新的传感器输入。没有磁力计绝对航向，偏航是相对角度；「姿态回正」重新以当前重力建立参考，不清除零偏。

## 校准与高级设置

入口：**手柄测试 → 体感与校准 → 校准与高级设置**。沿用当前设备及输入源，返回测试页不会切断传感器。

三条角速度轨道中点表示 0，分别为俯仰 X、偏航 Y、横滚 Z。轨道显示 ±5 °/s，超出时点停在端点，旁边数字继续显示实际速度。RAW 是原始输入，CAL 是减去零偏后的输入，顶端轨道还应用可选平滑。

### 手动静置校准

1. 将手柄平放在稳定水平桌面上，松手后点击「校准 · 3 秒」。
2. 页面显示剩余时间、真实样本数和进度。输入中断、超时、采样不足或移动会失败，保留已有零偏。
3. 完成后检查 CAL 是否接近 0，可点击「姿态回正」重建显示参考。
4. 「重置零偏」清除当前设备会话的零偏，自动校准开启时会重新等待静止。

要求至少 150 个有效样本；重力模长在 0.85–1.15 g，三秒内重力方向/向量变化不超过 0.035 g，模长标准差小于 0.02 g。角速度最大轴标准差小于约 0.183 °/s，相邻样本差小于约 2.44 °/s。

不再用“零偏必须小于 5 °/s”拒绝手动校准：本次实机 Switch Pro 平放时报告约 −16.7 °/s 的稳定俯仰零偏，旧规则无法校准。现在根据稳定性判定，使用 Welford 累计均值/方差，避免较大均值造成数值消减。必须真正放稳：仅靠六轴传感器不能从恒定水平旋转中可靠区分零偏。

### 自动漂移校准与平滑

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 静态下自动校准 | 启用 | 连续静止且样本稳定时更新零偏 |
| 角速度静止阈值 | 1.5 °/s | 校正后三轴角速度向量模长上限，可调 0.2–5 |
| 加速度变化阈值 | 0.035 g | 相对本次静止窗口起点的向量变化上限，可调 0.01–0.15 |
| 连续静止时长 | 3 秒 | 可调 2–10 秒；移动、断流会重置进度 |
| 使细微动作平滑 | 关闭 | 25 ms 时间常数抑制小抖动；角速度达到 8 °/s 时直接响应 |

自动校准还要求至少 100 个有效样本及较低角速度方差，不会只凭“等待了足够时间”完成。重力判定允许合理的模长误差，例如平放 1.04 g；变化检测比较向量，而不是要求模长精确为 1 g。自动校准用于修正小幅漂移，初始偏置较大时先执行手动校准，再自动跟踪后续变化。

参数修改立即生效，「保存校准设置」保存到本机 `bridge-settings.json`，下次启动沿用。零偏按设备会话独立计算，不跨设备共用，也不写入 Steam 或手柄固件。重新启动/重连时应检查 CAL，必要时重新静置校准。

Windows 输入源的校准和平滑用于本应用测试；NS2 BLE 输入源还把校正后的体感传给本应用的虚拟输出。Xbox 模式本身没有体感，NS1 模式的体感能力仍以对应协议实现为准。

界面和交互参考 Steam 截图；上述算法与阈值为本应用实现，不声称复刻 Steam 的闭源算法。

## 精简发布

运行目录只发布应用和必需运行组件：DLL、驱动安装器/服务、许可证和第三方声明。排除 docs、README、PDB、源码压缩包。开发文档继续保存在仓库的 `ControllerForwardingTool/docs` 中。

`tools/package-release.ps1` 创建新的发布目录，检查运行文件清单，并生成两个配套 ZIP：

- `NS2ProWin11-win-x64-20260926-r5.zip`：运行包，默认需要 .NET 10 运行时。
- `NS2ProWin11-third-party-sources-20260926-r5.zip`：SDL、libusb、VIIPER 源码，许可证和 SDL 构建脚本，不必解压到应用旁；分发时与运行包一起提供。

```powershell
dotnet run --project NS2ProWin11.Checks -c Release
./tools/package-release.ps1 -Version 20260926-r5
# 内置 .NET 的可选版本：
./tools/package-release.ps1 -Version 20260926-r5-self-contained -SelfContained
```

脚本不覆盖已有版本目录。Visual Studio 手动发布请选择新的空目录；构建不会删除旧目录中的历史 docs、symbols 或其他文件。许可证是随软件分发所需内容，保留在运行包。

## 验证记录

- Release 编译和默认检查通过，保留五种输出身份、BLE/FD2、NS1/NS2、震动和阻塞 UI 下 USB/IP 的回归检查。
- 新增样本检查：SDL/NS2 轴转换；俯仰、偏航、横滚 90°；两周旋转；倒置重力；重复、非法和断流时间戳；1.04 g 下自动收敛；移动/噪声拒绝；平滑与快速转动直通；大零偏手动校准及后续自动跟踪。
- 实际 Avalonia 窗口检查了浅色 Switch/Xbox 外壳、姿态卡片和完整校准页。用户确认实体 Switch Pro 已平放静止后，新版手动校准收到 1497 个有效样本，测得零偏约 `(-16.77, 0.46, 3.04) °/s`，一个完成时快照的 CAL 为 `(-0.03, 0.10, 0.04) °/s`。
- 随后自动静置校准也在该实体设备上达到 100%，继续跟踪零偏变化；另一个完成窗口采集了 1562 个有效样本。期间三轴校正值仍保持零附近，姿态回正按钮可正常使用。
- 运行 ZIP 的清单不含 docs、sources、README、PDB 或源码压缩包；驱动安装器、SDL、libusb、VIIPER 的文件哈希与仓库源文件一致。两个 ZIP 均完成 CRC 检查，源码包按原目录保留 11 个源码/构建/许可文件。
- 实机读数证明当前 Switch Pro 的手动静置校准有效；不等于所有手柄、固件和 NS2 BLE 都已实测。自由翻转、方向符号及 NS2 坐标转换的定量结果来自合成样本检查，仍需各型号实机逐轴复核。
