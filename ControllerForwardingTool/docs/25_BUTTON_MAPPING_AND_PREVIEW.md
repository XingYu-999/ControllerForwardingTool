# 输出按键映射与测试预览

日期：2026-09-26。

移除左侧“按键映射”入口及原来的说明占位页。在“虚拟手柄”启动区域下方，成功启动输出后显示“NS2 按键映射配置”。可逐键选择目标、“不输出”、应用保存或恢复默认并保存。

默认 GL 映射左摇杆按下（L3），GR 映射右摇杆按下（R3），其余保持原功能。这里的摇杆按下是开关量，不改变 X/Y 轴方向或位置。映射统一应用于 NS2 直连 BLE 和 Windows 识别的 NS2 输入，再交给 NS1、NS2、Xbox、PS5 或 Edge 编码器；其他实体手柄不套用 NS2 映射。所有输出模式共用这一配置。

配置保存在现有用户设置的 `Ns2Buttons` 字段。缺少字段的旧配置自动采用背键默认映射。保存成功才更新输出配置，下一帧生效。多个输入映射同一目标时按当前帧合并，所有输入释放后才释放目标；交换按键不递归映射。映射不会修改原始输入、陀螺仪、摇杆位置或时间戳。目标输出不支持的按键仍由该输出编码器忽略。

NS1 映射预览此前只屏蔽额外按键，同时被排除在 BLE 体感和手动震动代码路径外。现在预览读取已保存映射，并恢复实体 NS2 的体感显示、校准与手动振动。预览的振动直接作用于实体 NS2，不代表游戏经虚拟输出回传振动已经验证；实际虚拟输入仍通过“Windows 手柄”检查。该预览使用 NS2 BLE 源，不会冒充 Windows USB 输入预览。

验证：Release 构建 0 警告、0 错误，130 项检查通过。新增检查覆盖默认背键、合并/松键、交换、禁用、扳机重映射、配置迁移和保存、真实输入分发路径、五种输出编码及 Windows NS2 与其他型号隔离。XAML 编译通过；未启动新程序占用用户手柄，实际手动振动和 Windows 虚拟设备仍需实机确认。
