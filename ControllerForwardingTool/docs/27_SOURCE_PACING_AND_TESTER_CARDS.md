# 按源帧发送与手柄图标选择

## 频率设置

- `PushHz = 0`：跟随输入源。NS2 BLE 新帧直接唤醒发送，不再经 4 ms 轮询时钟；NS1 中断 IN 等待新帧，删除固定 `Task.Delay(8)`，IN 端点间隔改为 1 ms。消费者较慢时使用最新状态，不排队积累过期帧。
- `PushHz = -1`：按模拟目标 USB 参考频率限速。当前 NS1 125 Hz，其余支持的目标 250 Hz。名称明确为“按目标手柄默认 USB 上限”，不宣称这是所有零售固件的硬件极限。
- `PushHz = 66 / 125 / 250`：保留用户显式指定的固定频率。旧设置缺少值时仍默认为跟随输入源。
- 限速以高分辨率计时器实现；运行中可应用新的频率。NS1 端点描述变更需要停止并重新挂载虚拟设备。
- 实际接收仍受 USB 驱动、调度和下游后端影响。Windows 源由 SDL 提供可观察到的输入状态；这不保证能恢复 SDL 已合并的每份物理报文。

NS1 的挂起输入请求独立于控制/OUT 接收处理；响应写入串行化，UNLINK 取消待处理输入请求，断开取消全部挂起操作。初始化回复绕过源帧等待。没有新输入达到 250 ms 时归零，之后只发送低频中立状态保活。

## 测试页

- 删除输入源、Windows 设备和显示型号下拉框，改用手柄图片卡片分组选择。
- “手柄源”：NS2 BLE 和 Windows 识别的实体设备。型号图标用于识别，设备名称/ID 区分同型号设备。
- “模拟手柄”：当前五种输出身份。Windows 已枚举时查看实际接收；未枚举时查看保存映射的输出预览，点击预览不会启动驱动。
- 模拟身份在挂载/断开时保留选择，并在实际接收和预览之间切换；实体设备断开不会自动换到另一只实体手柄。
- 分类使用本应用的序列号和挂载期间观测到的设备身份，不把所有相同 VID/PID 的实体设备当作模拟设备。
- 预览取自输入桥已应用的保存配置。更改模拟型号、频率或重新加载配置不会覆盖用户保存的按键映射；未应用草稿不影响预览和实际输出。
