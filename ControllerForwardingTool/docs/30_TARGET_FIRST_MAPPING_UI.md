# 弹窗快速配置

适用版本：**1.0.1**；同步日期：2026-09-27。[更新日志](../../CHANGELOG.md) · [当前文档目录](../../docs/README.md)。

虚拟手柄连接成功后，导航栏才显示按键映射页。点击映射预览区的“快速配置”，打开逐项配置弹窗；双击输出按键则只录入该按键的映射源，双击空白处不启动向导。顶部不再显示快捷配置开关和录入选项。完整向导从左摇杆开始，接着是右摇杆，再配置当前输出型号支持的按键；蓝框标出当前目标。

双击单个输出按钮打开独立编辑弹窗：可以连续添加多个真实手柄按钮、键盘键和鼠标按键，列表中可逐个移除，点击“确认”后才写入草稿。鼠标左键使用独立的“绑定鼠标左键”勾选项，操作确认、移除及下拉框不会误绑定左键。完整快速配置则用“此项使用鼠标左键”按钮。取消或 Esc 丢弃弹窗中的未确认修改。

双击左、右摇杆时，弹窗分为“摇杆按下”和“摇杆”两个 Tab，默认打开“摇杆按下”来配置 L3 / R3。摇杆页在纯键鼠输入下显示上、下、左、右四个方向，点击对应源键后录入，也可清除方向或通过独立按钮绑定鼠标左键；重新绑定的键从原按钮或其他方向移走。实体手柄输入只需选择源左 / 右摇杆，也可先回中再推动源摇杆录入，两轴整体映射。两个 Tab 保留各自未确认的编辑；切换时需重新松键，避免误录。点击确认一起提交，取消或 Esc 一起丢弃。

页面通过“手柄状态 / 全部映射”切换同一块区域：前者显示输入与当前配置的输出，以及紧接在手柄图下的源输入 → 映射目标；后者以输出目标为一张卡片，集中列出映射到它的真实手柄、键盘和鼠标来源及数量。同一实际输出按钮的别名也合并，摇杆方向、未输出和不支持的目标保持区分。双击卡片会载入整组来源，可逐项添加、移除，或将整组改到另一个目标；确认前不修改草稿。保存与恢复默认操作在页面右上角。“键盘 / 鼠标补充”在新建 NS1 线路中开启，其他线路及旧配置缺省时关闭；开启后显示随宽度放大的键鼠图与体感设置；关闭保留绑定但停止补充输入。鼠标模式和补充设置均集中在映射页。弹窗保留页面滚动位置；完整向导最后一项在松键后完成。

键鼠输入分别录入左、右摇杆的上、下、左、右四个方向键。手柄输入要求推动一个源摇杆，完整映射其 X/Y 两轴；按钮、方向键及摇杆按下不能代替摇杆，L3/R3 会在普通按键步骤中单独配置。摇杆要先回中，键盘键或按钮要先释放，再进行下一项。摇杆漂移不会自动录入，一次按多个键或同时推动两个摇杆时需归零重试。

“跳过此项”保留该项原配置。向导完成、单项确认或下拉框修改后，立即使用当前草稿在本页测试，无需先保存。预览从原始输入重新计算按钮、键鼠绑定、摇杆方向、死区及体感来源；点击“应用并保存”才持久化并用于虚拟输出。Esc、取消、关闭弹窗、失焦或虚拟输出断开会丢弃本次弹窗未确认的录入，保留进入前已有的草稿。没有自动超时。

键鼠源显示在上方，输出手柄显示在下方；实体手柄仍左右对照。键盘键帽、鼠标外壳以有厚度的立体效果绘制，按下时橙色高亮并下沉，最近绑定的键显示蓝框；下方状态显示实际按键和鼠标移动量。预览只在映射页处于前台时读取键鼠状态，不抢占光标或启动虚拟输出。

键鼠快捷绑定支持原先未使用的键、鼠标中键和侧键。Esc、F8、Alt、Windows 键保留给取消和运行控制。自定义绑定优先于该物理键的默认行为，并直接指向选中的输出按钮，不重复经过默认逻辑按键映射。绑定后的 WASD 键不会再同时推动左摇杆，鼠标移动仍保留原右摇杆 / 陀螺仪模式。全部映射中可双击规则修改或移除来源；恢复默认会恢复整条线路的默认绑定。

键鼠方向映射保存于每条输出线路的 `KeyboardStickBindings`，通用默认左摇杆 WASD，1.0.1 新建 NS1 线路预设为 W/X/A/D；右摇杆方向键松开时仍由鼠标按所选模式控制。相反方向相互抵消，斜向限制在单位圆内。方向键绑定优先于该键的默认按钮功能，自定义按钮绑定优先于方向绑定。完整默认值见[配置说明](../../docs/03_CONFIGURATION_AND_LIFECYCLE.md)。

键鼠按钮绑定保存在 `KeyboardOverrides`，手柄摇杆映射保存在 `ControllerSticks`；原有逻辑按键映射仍保存在 `Ns2Buttons`。全部随输出线路独立保存；恢复默认同时恢复摇杆与按键。原始输入对照保持不变，手柄摇杆在源校准与死区处理后映射到目标。页面预览不代表 Windows 或游戏实际接收结果。

验证包含：激活点击隔离、松键 / 回中、单键限制、跳过、Esc 取消、键鼠四方向、禁止按钮映射摇杆、左右摇杆互换、配置迁移、线路独立保存与实际输入桥接。真实 Avalonia 弹窗分别以键鼠和手柄输入离线渲染检查。
