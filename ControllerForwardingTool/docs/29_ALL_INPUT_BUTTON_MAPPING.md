# 所有输入方式的按键映射

适用版本：**1.0.1**；同步日期：2026-09-27。[更新日志](../../CHANGELOG.md) · [当前文档目录](../../docs/README.md)。

按键映射支持 NS2 USB / 直连蓝牙、Windows 识别的 Xbox / Switch / PlayStation 等手柄，以及键盘 / 鼠标。虚拟输出成功启动且 Windows 已识别当前模拟手柄后，导航栏和虚拟手柄页才显示映射入口。可使用图形或下拉框配置，应用并保存后下一帧生效。

启动中、启动失败、停止或当前虚拟设备消失时，入口和页面均隐藏；若正停留在映射页，会取消按键录入并返回虚拟手柄页，保留本次未保存的映射草稿。实体输入源断开不影响入口，只要虚拟输出仍连接。

源图按物理按键位置识别，源列表按当前输入布局显示名称。键鼠列表同时显示默认键，例如“J / 空格 → A”“鼠标左键 → RT”。下拉框修改逻辑按键的输出目标；双击输出按键单独录入该键，点击快速配置可通过弹窗逐项配置键鼠方向键、手柄摇杆与按钮。PlayStation 的触摸板按下也可作为源。

所有源在转换到统一坐标后应用一次映射。交换按键不会递归，多个源映射同一目标时合并；原始输入对照不受影响。左右模拟扳机互换或合并时保留行程，普通按键映射到扳机时输出满行程，设为“不输出”时归零。源设备没有提供的按键不会被合成，目标不支持的功能仍由对应输出忽略。

映射按输出线路独立保存，恢复默认只影响当前线路；沿用原 `Ns2Buttons` 配置字段，以保持既有映射兼容。该字段现在作用于所有输入，不再限定 NS2。
