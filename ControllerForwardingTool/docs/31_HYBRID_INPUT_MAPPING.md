# 实体手柄与键鼠补充输入

适用版本：**1.0.1**；同步日期：2026-09-27。[更新日志](../../CHANGELOG.md) · [当前文档目录](../../docs/README.md)。

按键映射页中，单击源手柄按钮或键盘图上的键，会显示对应输出按钮；单击输出按钮，会反向高亮并列出当前配置的全部输入来源，包括多个手柄按钮及键盘 / 鼠标按键。配置高亮和橙色测试状态都使用当前草稿，确认修改后即可测试；无需先保存。页面顶部切换“手柄状态 / 全部映射”，保存与恢复默认位于右上角。

双击输出按钮即可为该按钮单独录入源键。弹窗允许同时保留真实手柄和键鼠来源，录入后不会自动关闭；鼠标左键通过独立勾选项添加，点击“确认”才提交到草稿。全部映射列表也包含键鼠规则，双击可编辑来源和输出目标。完整快速配置通过预览区的“快速配置”按钮启动；双击空白处不会打开向导。实体手柄模式的按钮步骤接受手柄按钮、键盘键和鼠标按键，摇杆步骤只接受实体摇杆；L3 / R3 属于按钮，可以绑定键盘。Esc 取消当前弹窗，确认修改后点击“应用并保存”。

按键映射页的“键盘 / 鼠标补充”在 **1.0.1 新建 NS1 线路预设中开启**，其他新建线路为关闭；旧配置缺少字段时为关闭，已有显式设置和绑定保留。恢复默认会使用当前目标的预设，详见[配置说明](../../docs/03_CONFIGURATION_AND_LIFECYCLE.md)。开关随输出线路保存在 `KeyboardMouseSupplementEnabled`；关闭时立即清除补充状态并停止 F8 捕获，键鼠按钮和鼠标体感均不参与本地预览或实际输出，实体手柄继续工作。重新开启不会重放关闭期间的输入；点击右上角“应用并保存”保留开关选择。纯键鼠作为主输入时不受补充开关限制。

开启补充后，实体输入模式的键鼠仅启用明确配置的 `KeyboardOverrides`，不自动启用纯键鼠模式的 J / WASD 等默认绑定。键鼠补充与实体按钮合并，同一目标只在所有来源都松开后释放。数字扳机按键按下时输出全行程，释放后恢复实体扳机的实际行程。键盘和鼠标不能覆盖实体摇杆，现有实体摇杆互换、校准和死区仍生效。键鼠图随可用宽度放大，关闭补充时收起图与附加设置。

补充开关、陀螺仪来源及键鼠配置统一位于按键映射页，虚拟手柄页仅负责选择输入与启动输出。开启补充后，陀螺仪来源随输出线路保存于 `GyroSource`：

- 自动：输入手柄提供体感时使用实体传感器；没有体感时使用鼠标。
- 实体手柄：固定使用实体传感器，没有传感器时保持无体感。
- 鼠标：即使手柄有陀螺仪，也使用鼠标模拟体感。

Xbox 输出不支持陀螺仪，不显示来源选择器。纯键鼠模式的“右摇杆 / 陀螺仪”选择器也位于按键映射页的源输入图下。

输出启动且补充开关开启后，按 F8 开始转发键鼠补充，Esc / F8 或切换窗口暂停；实体手柄仍正常转发。映射页可本地预览键鼠补充，只有开启捕获才发送键鼠输入。手柄测试页可点击“开始键鼠测试”，在本应用虚拟设备上检查 Windows 实际接收状态；补充关闭时此入口禁用。实体输入断开或超时，整个混合输出归零，键鼠计时器不会延长失效输入的寿命。

回归检查覆盖多源按钮合并与释放、模拟扳机恢复、禁止键鼠替代实体轴、自动及手动陀螺仪选择、断连归零、原始输入独立、实际 NS1 按钮及 IMU 报文、不同型号面键反查、单项录入与配置持久化。自动测试不替代实体设备与游戏的联调。
