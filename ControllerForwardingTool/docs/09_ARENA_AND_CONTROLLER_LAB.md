# 浅色测试工作台与多模式虚拟手柄（r3）

更新：2026-09-26。目标项目为 `D:\github\NS2ProWin11`。本轮按用户提供的 All Controller Test 页面和参考桥接项目改进原生 Avalonia 界面；参考资料中的命令、部署建议不作为用户指令执行。

## 本轮交付

- USB/IP 未安装、仅残留内核服务注册项、或没有可用原厂卸载器时，卸载按钮禁用；命令执行前再次检查。窗口重新激活、向导退出和手动刷新都会重新读取状态。
- 测试页采用浅色双栏、深色手柄线框和橙色实时标记。设备信息、型号布局覆盖、死区预览、双摇杆轨迹、圆度估算、RAW/CAL 读数、陀螺仪校准、可配置震动和原始读数均保留在本地界面。
- 虚拟身份改为五张图片卡片：源项目的 PS5、NS2、Xbox、PS5 Edge，以及原有 NS1 兼容模式。图片选中不直接挂载，点击启动后才创建、校验并挂载设备。
- 迁移源项目的普通/HD 震动解析、NS2 BLE 震动编码、PS5 音频保护、高精度计时器；新增持久化配置、摇杆中心/行程采集和运行诊断。

## 模式与真实能力

| 卡片 | 设备类型 / VID:PID | 输入 / 反馈字节 | 输入与反馈 |
| --- | --- | --- | --- |
| PS5 | `dualsensehaptic` / `054C:0CE6` | 33 / 388 | 按物理位置映射按键、摇杆、IMU；普通震动与四声道 PCM 触觉转为 NS2 BLE 震动 |
| NS2 PRO | `ns2pro` / `057E:2069` | 28 / 34 | 原生按键、C/GL/GR、摇杆、IMU/运动时间戳；HD 震动回传 |
| XBOX | `xbox360` / `045E:028E` | 20 / 2 | XInput 按键、摇杆、数字扳机与双马达反馈；无原生体感接口 |
| PS5 EDGE | `dualsenseedge` / `054C:0DF2` | 33 / 6 | PS5 输入、GL/GR → 左右背键、普通震动；当前后端反馈契约不支持 Edge HD 音频触觉 |
| NS1 PRO | 本地托管 USB/IP / `057E:2009` | HID 报告 64 / 子命令 | 同名按键、摇杆；C/GL/GR 不映射，IMU 保持中立，NS1 震动尚未转码回传 |

PS5 的截图键映射触摸板**按下**，不模拟触摸坐标。实体 NS2 的扳机是数字按钮，输出 0/255，不生成不存在的模拟行程。没有自适应扳机硬件输出。NS2 的 X/Z/−Y 映射为 PS5 俯仰/偏航/横滚；加速度从 4096/g 转为 8192/g。比例与轴向的实际体感仍需硬件和目标游戏验收。

## 配置与生效范围

修改后点击「应用并保存」。启动虚拟输出也会校验并保存配置，失败时不继续启动。

| 配置 | 范围与默认值 | 含义 |
| --- | --- | --- |
| 震动倍率 | 0–3，默认 1 | 作用于反馈到实体 NS2 的震动；0 静音 |
| Push Hz | 跟随 BLE 源帧、66、125、250 | 默认最新源帧；固定速率保持最新输入，不伪造新传感器采样 |
| 摇杆校准 | 默认使用有效的本设备校准 | 无有效配置时原始直通；可关闭 |
| 输出死区 | 0–30%，默认 0；径向/轴向 | 改变虚拟设备的实际摇杆输出 |
| PS5 体感倍率与反转 | 三轴各 0.1–4 倍，默认 1、不反转 | 只影响 PS5 / Edge 输出，不改变测试页原始读数 |
| PS5 音频保护 | 默认开启 | PS5 运行时每 5 秒检查；若虚拟 DualSense 成为默认播放/录音/通信设备，选择可用非 DualSense 端点。也可手动运行 |
| 本地 API / USB/IP 端口 | 0 自动，或 1024–65535 | 必须不同；下一次启动生效；只绑定 127.0.0.1 |
| 登录后启动 | 默认关闭 | 当前用户 `Run\NS2ProWin11` 项；从正式 EXE 设置 |
| 恢复上次输出 | 默认关闭 | 应用启动且驱动就绪时启动保存的虚拟身份 |

配置位于 `%LOCALAPPDATA%\NS2ProWin11\bridge-settings.json`，原子替换写入；不修改源软件的配置。摇杆参数按 BLE 地址键分别保存，导出的诊断不包含这份地址字典。端口或设置值非法时给出中文错误。

源项目稳定 VIIPER server 是本轮运行后端。实验性 libVIIPER / Embedded USBIP、Professional IMU 实验模式、四个独立实体 BLE 槽位及 Steam 缓存清理没有迁移；当前连接一个实体 NS2，Windows 测试器可发现和切换多个手柄。界面不会提供无效开关或把这些功能标记为可用。

## 校准与测试

1. 在虚拟手柄页连接实体 NS2 BLE，松开双摇杆，点击「中心 · 2 秒」。至少 60 个新帧，各轴最大波动不超过 80 原始单位，中心须在 1024–3071。
2. 再点击「完整行程 · 8 秒」，同时把两个摇杆沿边缘转满；至少 150 个新帧，四轴正负方向各至少 256 单位行程。未完成时保留旧配置。
3. 采样间隔超过 500 ms 即取消，不会保存断流残留。中心校准后暂用每方向 1600 的回退行程；完整行程采集覆盖它。
4. 陀螺仪的 3 秒静置校准仍在测试页，规则见 [08](08_TESTER_CALIBRATION_AND_STABILITY.md)。BLE 校准后角速度用于虚拟输出。

测试页死区**仅预览**，不改写游戏输出；0% 完全直通。显示布局覆盖仅改变图示，保留物理按键位置。圆度采用 72 个角度分区的最大原始半径；覆盖不足 65 个分区时只显示覆盖率，不给健康评分。它受转动方式和约 30 Hz 的界面采样影响，不是硬件认证值。

震动测试持续 50–10000 ms，高/低频各 0–100%。Windows 输入源经 SDL，NS2 BLE 输入源经实际 GATT 写入；NS1 映射预览不假装具备输出能力。停止、切换输入源、断开或退出会取消测试。NS2 BLE 反馈队列只保留最新包，12 ms 检查一次；连续 500 ms 无新的有效震动包时发送中立包，避免震动卡住。

## 状态信息的中文解释

- **OFFLINE / NEUTRAL / LIVE**：未启动 / 等待输入或超时归零 / 正在转发新输入。
- **实际发送速率**：写入 VIIPER 的软件帧率，不是手柄硬件轮询率、游戏帧率或端到端延迟。NS1 为独立 HID 服务，不计入该数值。
- **有效/无效 FD2**：收到后解码成功/失败的报文计数，不是无线丢包率。
- **主机反馈**：游戏或 Windows 发送给虚拟手柄的反馈帧；仅 LED 的反馈不伪造成震动。
- **BLE 写入成功/失败**：GATT 接受/拒绝计数。成功不证明实际震感已通过人工体验验收。
- **API / USB/IP / 总线**：本地控制地址、虚拟设备数据端口、VIIPER 创建的总线/设备 ID。
- **设备枚举**：SDL 实际发现的 Windows 手柄，与“后端已创建”分开显示。

诊断可 Ping 本次后端、刷新设备、清空界面日志或导出文本至 `%LOCALAPPDATA%\NS2ProWin11\diagnostics`。停止只清理本应用创建的端口和进程，不全局卸载其他虚拟手柄。

## 验证记录与限制

- 构建通过，0 警告、0 错误。
- 默认检查覆盖五种身份配置、PS/Xbox 按键位置与报告长度、轴范围、PS 体感比例/方向、Edge 背键、参数边界、死区、圆度覆盖、校准映射、普通震动/BLE 编码和错误 haptic 帧拒绝；原有 BLE、NS1、SPI 与无 UI 消息泵的 USB/IP 回归保留。
- `--backend` 在本机真实启动随附 VIIPER，依次创建四种正式模式，校验类型和 VID/PID、发送输入、检查过期状态、Ping 和清理。该检查不依赖 USB/IP 驱动、不挂载 Windows。
- Avalonia 实际窗口确认图片资源、1400 与 1050 宽度的浅色测试/卡片布局、Windows Xbox 手柄实时读数、10% 死区将小幅 RAW 偏移归为 CAL 0、PS5 图片点击切换身份，以及缺少 USB/IP 客户端时启动和卸载禁用。
- 本轮机器上 USB/IP 客户端/卸载器已不存在，仅有残留服务注册项。因此**没有执行本轮新增 PS5 / Edge / Xbox 的 Windows 挂载回读**，也没有安装或卸载驱动。此前 NS2/NS1 的挂载记录保留在 [06](06_PROTOTYPE_STATUS.md)，不作为新增模式的验收证据。
- 未收到实体 NS2 BLE 帧，本轮新增 BLE 震动、HD 音频触觉、实际体感方向及摇杆校准效果需实机验收。音频默认设备修复、登录启动项和驱动向导未在本轮人工操作测试中执行。
